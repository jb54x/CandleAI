CANDLE AI - ANDROID 15

This project targets Android 15 (targetSdk 35 / compileSdk 35).

BUILD:
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Connect an Android phone or use an emulator.
4. Build > Build APK(s).
5. APK will be under app/build/outputs/apk/debug/

IMPORTANT:
The included analyzer is a frontend demo and uses randomized demo signals.
It is NOT a real prediction engine and does not guarantee results or profits.
For a production AI analyzer, connect the JavaScript frontend to a secure backend/API.
