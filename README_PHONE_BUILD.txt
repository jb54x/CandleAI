PHONE-ONLY APK BUILD

1. Create a GitHub repository named CandleAI.
2. Upload ALL contents of this folder (not the ZIP itself).
3. Open Actions.
4. Select "Build Candle AI APK".
5. Tap "Run workflow".
6. Wait for the green check.
7. Open the completed workflow and download artifact:
   CandleAI-Android15-APK
8. Extract the artifact and install app-debug.apk.

Target/compile SDK: 35 (Android 15).
Java: 17.
Gradle: 8.9.

The included candle analyzer is a demo and does not guarantee future candle movement or profit.
